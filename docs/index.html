High Performance Architecture

Engineered for Massive Datasets

Built from the ground up to solve memory exhaustion bottlenecks when analyzing massive enterprise files on ordinary workstations.

DuckDB Out-of-Core Execution

Leverages vectorized columnar execution and automatic disk spillover buffer. Never suffers from Out-of-Memory crashes even when datasets exceed physical RAM.

Disk Spillover Columnar Pushdown RAM Capping

Streaming XML & Parallel Parquet

High-speed chunked streaming XML parser using iterparse with immediate element clearance. Converts 60GB+ XML trees into indexed Parquet using all available CPU cores.

O(1) Memory Multi-Process Indexing Union By Name

Dynamic Schema Auto-Detection

Automatically scans incoming tabular files, classifying columns into Text, Numeric, Categorical, and Date types. Dynamically populates specialized filter controls.

Format Sniffing Auto Type Coercion Regex & Range Filters

Multi-Column Aggregations & Pivot

Perform complex Group By operations across arbitrary dimensions with instantaneous SQL execution. Calculate sums, counts, averages, and generate instant visualizations.

Dynamic Metrics Instant Charts Distinct Extraction

Global Multi-Token Instant Search

Search across every text column simultaneously with sanitization for quotes and multi-word tokenized conjuncts. Seamless pagination offset recovery ensures no false empty results.

Multi-Word AND Typo Tolerant Auto Offset Reset

Streaming Exporter (CSV, Parquet, JSON)

Push filtered results directly to compressed Parquet or CSV on disk via analytical stream pipelines without staging intermediate rows in RAM.

Zero Overhead Direct Download Custom Delimiters

Developer Installation

Run from Source in 60 Seconds

Clone the repository and run immediately with Python 3.10, 3.11, or 3.12.

bash / zsh 
# 1. Clone the repository
git clone https://github.com/Vinello28/grabber.git
cd grabber

# 2. Run one-click startup script (handles virtualenv & dependencies automatically)
./run.sh          # macOS & Linux
run.bat           # Windows Command Prompt

# Or manual execution:
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run.py
